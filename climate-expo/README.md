# 2050 기후 도시 엑스포 — 수업용 웹앱

초등 6학년 사회 「세계의 다양한 기후와 생활 모습」 개념 학습 뒤에 하는 프로젝트 수업용 앱입니다.
6팀이 기후 카드를 뽑고, 그 기후에 맞는 2050년 미래 도시를 설계하고, 재난을 버틴 뒤 엑스포에서 서로의 도시에 투자합니다.

- 핵심 목표: **"이 기후라서 이렇게 지었다"** 를 설명하기
- 흐름: ① 뽑는다 → ② 짓는다 → ③ 버틴다 → ④ 자랑한다
- 학생 화면: `index.html` · 교사 화면: `admin.html`

---

## 1. 어떻게 생겼나

```
[학생·교사 기기] ──화면──▶ GitHub Pages (climate-expo/index.html, admin.html)
        │
        └──데이터 요청──▶ Google Apps Script 웹앱 (climate-expo/gas/*.gs)
                                  │
                                  └──▶ Google 스프레드시트 (탭 10개)
```

| 폴더/파일 | 역할 |
|---|---|
| `index.html` | 학생 화면 (팀 코드 → 이름 선택) |
| `admin.html` | 교사 화면 (PIN) |
| `assets/config.js` | **Apps Script 웹앱 주소(API_URL)를 넣는 곳** |
| `assets/style.css`, `common.js`, `student.js`, `admin.js` | 화면 코드 |
| `gas/` | Apps Script 서버 코드 (clasp `rootDir`) |
| `dev/` | 로컬 시험용(배포에 필요 없음) |

모두 무료 도구입니다(GitHub Pages, Google Apps Script, Google 스프레드시트).

## 2. 배포 방법 ① 복사-붙여넣기 (추천)

### 2-1. 스프레드시트와 서버 만들기

1. Google 드라이브에서 **새 스프레드시트**를 만들고 이름을 `2050 기후 도시 엑스포`로 바꿉니다.
   - 기존 학급 앱(그로스포인트)과는 **다른 스프레드시트**를 씁니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 처음 있는 `Code.gs`의 내용을 모두 지웁니다(파일 이름을 `Api`로 바꿔 써도 됩니다).
4. 왼쪽 **파일 ＋ → 스크립트**로 아래 7개 파일을 만들고, 이 저장소 `climate-expo/gas/`의 같은 이름 파일 내용을 그대로 붙여넣습니다.
   `Api` · `AdminApi` · `Config` · `Data` · `Logic` · `Setup` · `StudentApi`
   (편집기가 `.gs`를 자동으로 붙이므로 이름만 입력)
5. (권장) 왼쪽 **⚙ 프로젝트 설정 → "편집기에서 appsscript.json 매니페스트 파일 표시"** 를 켜고, `appsscript.json` 내용을 `gas/appsscript.json`으로 바꿉니다. (시간대 `Asia/Seoul`, V8 런타임)
6. 💾 저장 후, 위쪽 함수 목록에서 **`setupSheets`** 를 고르고 **▶ 실행**합니다.
   - 처음에는 권한 승인 창이 뜹니다. 내 계정 선택 → (경고가 나오면) 고급 → 프로젝트로 이동 → 허용.
   - 스프레드시트에 탭 10개(Settings, Teams, Students, …)가 생기면 성공입니다.

### 2-2. 웹앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생이 로그인 없이 휴대폰에서도 쓰려면 꼭 이것)
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 **복사 버튼으로** 복사합니다.
   - ⚠️ 이 주소를 브라우저로 연 뒤 **주소창에 바뀌어 보이는 주소**(`script.googleusercontent.com/macros/echo?…`)를 복사하면 안 됩니다. 그건 한 번만 쓰는 응답 주소라 앱이 연결되지 않습니다.
   - 나중에도 스프레드시트 메뉴 **기후 엑스포 → 웹앱 주소 확인**에서 볼 수 있어요.
5. 확인: 그 주소를 브라우저 새 탭에 붙여넣으면 `{"ok":true,...}` 글자가 보여야 합니다.

### 2-3. 화면(GitHub Pages)에 주소 연결

1. GitHub 저장소에서 `climate-expo/assets/config.js` 를 열고 ✏️(편집) 버튼을 누릅니다.
2. `API_URL: ''` 따옴표 안에 복사한 웹앱 주소를 붙여넣고 **Commit changes**.
3. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 이 앱이 들어 있는 브랜치 / `(root)`로 고르고 Save.
4. 몇 분 뒤 주소
   - 학생: `https://<GitHub아이디>.github.io/<저장소>/climate-expo/`
   - 교사: `https://<GitHub아이디>.github.io/<저장소>/climate-expo/admin.html`
   - 이 저장소 기준: `https://jongku93.github.io/KJG/climate-expo/`

> 저장소 루트의 `.nojekyll` 파일은 그대로 두세요(파일이 그대로 공개되도록 하는 설정).

### 2-4. 서버 코드를 고친 뒤 다시 배포할 때 (주소 유지)

Apps Script에서 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**.
**"새 배포"를 또 만들면 주소가 바뀌어** config.js도 다시 고쳐야 합니다.
시트 내용(카드 문구, 설정 값)만 고친 경우에는 다시 배포할 필요가 없습니다.

## 3. 배포 방법 ② clasp (명령줄)

```bash
npm install -g @google/clasp
clasp login
cd climate-expo
cp .clasp.json.example .clasp.json
# .clasp.json 의 scriptId 를 바꿉니다.
#  (2-1의 1~2번으로 스프레드시트에 붙은 Apps Script를 만든 뒤,
#   ⚙ 프로젝트 설정 → 스크립트 ID 복사)
clasp push          # gas/ 폴더가 올라갑니다 (rootDir: gas)
```

그다음 2-1의 6번(`setupSheets` 실행)과 2-2, 2-3을 똑같이 합니다.
코드를 고친 뒤에는 `clasp push` → 2-4(새 버전 배포).
`.clasp.json`은 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.
(clasp 버전에 따라 명령 이름이 조금 다를 수 있습니다.)

## 4. 시트 구조

각 탭의 첫 행은 머리글이며, 처음 실행할 때 자동으로 만들어집니다. 머리글 이름으로 열을 찾기 때문에 **열 순서를 바꿔도 되지만 머리글 글자는 바꾸지 마세요.** 빠진 열은 교사 화면 [설정 → 시트 구조 점검]으로 다시 만들 수 있습니다.

| 탭 | 내용 | 교사가 직접 고쳐도 되는 것 |
|---|---|---|
| Settings | PIN, 학급 이름, 단계 열림, 코인 수, 포인트 기준, AI 사용 규칙 | 값(B열) |
| Teams | 팀ID, 팀 이름, 팀 코드, 기후, 재난ID, 포스터 링크, 1~4단계 팀별 열림/잠김 | 팀 이름, 팀 코드, 1~4단계(빈칸/열림/잠김) |
| Students | 번호, 이름, 팀ID, 직책, 최근 접속 | 이름, 팀ID, 직책 |
| Climates | 기후, 특징, 전통 생활 힌트, 대표 지역, 아이콘, 색상, 사용 | 전부 (기후 이름은 뽑힌 뒤엔 바꾸지 않기) |
| Disasters | 재난ID, 기후(또는 `공통`), 재난 이름, 상황, 생각해 볼 질문, 사용 | 전부, 행 추가 가능(ID 중복 금지) |
| Designs | 팀별 설계 기록(직책별 만든 것·이유, 전통 계승, AI 기록) | 필요하면 |
| DisasterResponses | 팀별 재난 대응 | 필요하면 |
| Votes | 투자 기록(투표자, 대상 팀, 코인, 이유) | 지우지 않기(취소는 교사 화면에서) |
| Export_Points | 학생별 포인트 계산 결과 | 연동상태 열 |
| World_Buildings | 우승 도시 기록 | — |

시트를 직접 고치면 앱에는 바로(늦어도 30초 안) 반영됩니다.

### 나중 확장을 위해 확정한 탭

**Export_Points** (그로스포인트 연동용, 한 줄 = 학생 1명의 항목 1개)

| 열 | 예 | 설명 |
|---|---|---|
| 지급ID | `EXPO-2026-7-STAGE1` | `PROJECT_ID-번호-항목코드`. 같은 지급을 두 번 넣지 않게 하는 열쇠 |
| 번호 / 이름 / 팀ID | 7 / 학생7 / T2 | |
| 항목코드 | `STAGE1` `STAGE2` `DISASTER` `STAGE4` `VOTE` `WIN1` `WIN2` `WIN3` | |
| 항목 / 포인트 | 1단계 완료 / 5 | 포인트는 Settings의 `POINT_*` 값 |
| 계산일 | | 내보낸 시각 |
| 연동상태 | (빈칸) | 그로스포인트에 반영한 뒤 표시용 |

**World_Buildings** (3D 월드 건물용): 팀ID, 도시 이름, 기후, 한 줄 소개, 포스터 링크, 득표, 등록일

### 포인트 기준 (Settings에서 수정)

| 항목 | 기본값 | 받는 조건 |
|---|---|---|
| POINT_STAGE1 | 5 | 팀이 기후를 뽑고 팀원 모두 직책 선택 |
| POINT_STAGE2 | 10 | 내 직책 칸 2개 + 팀 공통 칸(도시 이름·소개·전통 2·AI 2) 모두 작성 |
| POINT_DISASTER | 10 | 팀 재난 대응 2칸 작성 |
| POINT_STAGE4 | 10 | 팀 포스터 링크 제출 |
| POINT_VOTE | 3 | 본인이 투자 투표 참여 |
| POINT_WIN_1/2/3 | 20/10/5 | 투자 순위 1·2·3위 팀원 (같은 코인이면 같은 순위) |

## 5. 수업 당일 교사 체크리스트

### 수업 전 (한 번만)
- [ ] 2장 배포를 마치고, 학생 주소·교사 주소가 열리는지 확인
- [ ] 교사 화면 → **설정**에서 `ADMIN_PIN`을 6자리 이상으로 바꾸기, `CLASS_NAME` 입력
- [ ] **명단·팀 코드**에 명단 붙여넣기 → 저장 (예: `1,김하늘,1` / 팀번호를 비우면 자동 배정)
- [ ] 휴대폰 한 대로 학생 화면에 들어가 팀 코드 → 이름 선택까지 해 보기
- [ ] (확인 필요) 학교 Canva 계정에서 "링크가 있는 모든 사용자" 공유가 되는지 미리 시험

### 1차시 — 뽑는다 (기후 카드 + 직책)
- [ ] **단계·재난**에서 1단계만 켜져 있는지 확인 (처음 기본값)
- [ ] **명단·팀 코드 → 📺 크게 보기**로 팀 코드를 화면에 띄우기
- [ ] 학생: 미션 탭에서 의뢰서·AI 사용 규칙 읽기 → 1단계 탭에서 **팀 대표 한 명**이 카드 뽑기 → 각자 직책 고르기
- [ ] **진행 현황**에서 모든 팀 "1 뽑는다 ✓" 확인
- [ ] 문제: 실수로 다시 뽑아야 하면 단계·재난 → [기후 다시 뽑게 하기]

### 2차시 — 짓는다 (설계 기록)
- [ ] 2단계 켜기 (1단계는 켜 둔 채로 두어도 됨. 직책을 고정하려면 1단계 끄기)
- [ ] 학생: 내 직책 칸 2개(만든 것 / 이 기후라서 이유) + 팀 공통 칸 작성. 글은 자동 저장
- [ ] 진행 현황의 빨간 칸(미작성)을 보며 순회 지도. [설계 전체 보기]로 내용 확인
- [ ] 강조: 이유 칸에 기온·비·바람·계절 같은 **기후 특징**이 들어가야 함 (화면에 💡 힌트가 뜸)

### 3차시 — 버틴다 (재난)
- [ ] 2단계는 **켜 둔 채로** 3단계 켜기 → 학생 화면에 재난 경보
- [ ] 팀이 직접 뽑게 하거나, [🌪️ 재난 카드 배부]로 한꺼번에 나눠 주기 (배부하면 학생은 카드를 뒤집어 확인)
- [ ] 학생: 버티는 방법 + 설계에서 고친 점 작성, 필요하면 2단계 칸도 수정
- [ ] 특정 팀만 늦게/먼저 열려면 팀별 열기·잠그기 표 사용

### 4차시 — Canva 포스터 제작
- [ ] 4단계 켜기 → 학생: Canva로 포스터 제작 → 공유 링크 제출 (팀당 1개, 다시 내면 교체)
- [ ] 진행 현황에서 포스터 링크를 눌러 다른 기기에서도 열리는지 확인
- [ ] 엑스포 관람 탭에서 다른 팀 도시를 미리 살펴보게 하기

### 5차시 — 엑스포 (투자 + 발표)
- [ ] **투표·결과 → 투자 투표 열기** → 학생: 코인 10개를 다른 팀에 나눠 투자 (제출 후 수정 불가)
- [ ] 투표 진행 현황에서 미투표 학생 확인. 실수한 학생은 명단·팀 코드 탭에서 [취소]
- [ ] **🏆 발표 모드**로 꼴찌부터 한 팀씩 공개 (→ 키 또는 [다음])
- [ ] **결과 공개** 켜기 → 학생 화면에 순위·우승 도시
- [ ] **포인트·월드 → 계산해서 Export_Points에 기록**, 우승 도시 **월드에 등록**

## 6. 자주 묻는 문제

| 증상 | 해결 |
|---|---|
| "서버 주소(API_URL)가 설정되지 않았어요" | `assets/config.js`에 웹앱 주소를 넣고 커밋. Pages 반영까지 몇 분 걸림 |
| setupSheets 실행 시 "스프레드시트를 찾을 수 없어요" | 스프레드시트 메뉴가 아닌 곳(script.google.com, 드라이브)에서 만든 **독립형 스크립트**라서 그래요. ⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가 → 속성 `SPREADSHEET_ID`, 값 = 스프레드시트 주소의 `/d/` 와 `/edit` 사이 글자 → 저장 후 다시 실행. (이 경우 시트 위 '기후 엑스포' 메뉴는 생기지 않고, 시트를 직접 고친 내용은 최대 30초 뒤 반영) |
| "서버 응답을 읽지 못했어요" | 웹앱 배포의 액세스 권한이 **모든 사용자**인지 확인. 주소가 `/exec`로 끝나는지 확인 |
| 코드를 고쳤는데 그대로 | 2-4처럼 **새 버전**으로 배포했는지 확인. 브라우저 새로고침 |
| 팀 코드가 안 맞음 | 교사 화면 명단·팀 코드 탭의 코드 확인 (O/0, I/1 같은 헷갈리는 글자는 쓰지 않음) |
| 학생이 다른 기기로 바꿈 | 같은 팀 코드와 이름으로 다시 들어오면 그대로 이어짐 |
| 같은 칸을 두 명이 동시에 고침 | 나중에 저장한 학생에게 "친구가 먼저 고쳤어요" 창이 떠서 고를 수 있음 |
| 팀원이 4명이 아님 | 3명이면 빈 직책 칸은 팀원 누구나 작성 가능. 5명이면 교사가 명단·팀 코드 탭에서 직책을 직접 지정 |
| "지금 친구들이 한꺼번에 저장하고 있어요" | 동시 저장이 몰린 경우. 잠시 뒤 다시 누르면 됨 |
| 처음 접속이 느림 | Apps Script가 잠깐 쉬다가 깨어날 때 몇 초 걸릴 수 있음 |

## 7. 개인정보·보안 메모
- 학생 로그인은 팀 코드 + 이름 선택뿐(비밀번호 없음, 수업용 설계). 명단에는 **이름만** 넣고 다른 개인정보는 넣지 마세요.
- 웹앱 주소와 팀 코드를 아는 사람은 학생 화면을 열 수 있습니다. 수업이 끝나면 팀 코드를 새로 만들거나, Apps Script **배포 관리**에서 배포를 보관(중지)하세요.
- 교사 PIN은 시트(Settings)에 있으므로 스프레드시트를 학생과 공유하지 마세요. PIN을 8번 틀리면 5분 동안 로그인이 막힙니다.
- 동시에 쓰는 기능(기후 뽑기, 직책, 저장, 투표)은 LockService로 한 번에 하나씩 처리합니다. 화면은 20초마다(교사 화면은 12초마다) 새 내용을 받아옵니다.
