# 도레미 작곡 공책

초등학교 6학년 가락 만들기 연습·수행평가용 웹 작곡 프로그램입니다. 설치 없이 `index.html` 파일 하나를 브라우저(크롬·엣지·웨일·사파리)로 열면 바로 쓸 수 있습니다. 인터넷 연결도 필요 없습니다.

## 기능
- **조**: 장조 15개 + 단조 15개(조표 ♯/♭ 0~7개). 조를 바꾸면 이미 쓴 가락도 함께 옮김(조옮김, 끌 수 있음)
- **박자**: 2/4, 3/4, 4/4, 6/8, 3/8, 9/8, 12/8, 2/2 · **마디 수**: 4/8/12/16/24
- **음표**: 온·점2분·2분·점4분·4분·점8분·8분·16분음표 / **쉼표**: 같은 8종
- **임시표**: 올림표(♯)·내림표(♭)·제자리표(♮)를 음표 머리에 끌어다 놓거나 편집 줄·단축키로 붙임. 마디 안 같은 자리 음에 계속 적용되는 규칙대로 소리 남
- 끌어다 놓기 / 눌러서 연속 놓기, 위아래로 끌어 음높이 바꾸기, 화음(3개까지), 가사, 계이름·음이름 표시, 마디 복사·붙여넣기, 되돌리기
- 마디마다 박 채움 막대(꼭 맞으면 초록색), 스스로 점검 목록(박·음표 종류·쉼표·으뜸음 마침 등)
- **재생**: 피아노·리코더·실로폰·바이올린·오르간, 드럼 반주, 메트로놈, 예비박, 반복
- **화음 길잡이**: 마디마다 Ⅰ·Ⅳ·Ⅴ·Ⅴ7 지정(진행 틀 한 번에 넣기), 첫 박 음이 화음 구성음인지 초록/주황 표시, 화음 반주 재생·MIDI 반주 트랙
- **작곡 이론 탭**: 으뜸음과 음계, 주요 3화음, 화음의 이야기(Ⅰ–Ⅳ–Ⅴ–Ⅰ), 마침꼴(온마침·반마침), 화음에 어울리는 가락, 악곡의 짜임, 장조와 단조, 작곡 순서 — 8개 레슨. 예시는 고른 조로 바뀌고 소리로 들을 수 있음
- **사용 설명서 탭**과 **둘러보기(단계별 안내)**
- **저장**: MIDI(.mid), 악보 그림(.png), 인쇄/PDF, 작품 파일(.json) 저장·불러오기, 브라우저 자동 저장

## 파일 구성
- `index.html` — 배포용 완성 파일(이것만 있으면 됨)
- `src/app.html` — 원본. 고친 뒤 `python3 tools/build.py`로 `index.html`을 다시 만듦
- `tools/glyphs.json` — Bravura 글꼴에서 뽑은 악보 기호 모양, `tools/extract_glyphs.py` — 뽑는 스크립트
